📌 Django Notes & Tasks App

Веб-приложение для создания, редактирования и удобного управления личными заметками и задачами.

🚀 Функционал 
 * Создание, просмотр, редактирование и удаление заметок
 * Постраничная навигация (Paginator) и отображение текущей даты.
 * Удобный и современный интерфейс в тёмных тонах.
